# venue — where writing goes

- **Tier**: catalog
- **Prefix**: `venue-`
- **Purpose**: a journal, conference, publisher, magazine, or platform the
  user submits to: its rules, dates, and the user's standing with it. Load-
  bearing for anyone who writes on deadlines.

## Signals
- submission folders, publisher correspondence, CFP links in notes,
  `camera-ready/` dirs, journal LaTeX classes (`IEEEtran.cls`, etc.)
- conversation: "the TMI deadline", "my editor at…"

## Required sections
- `## Rules` — format, length, style guide, anonymization, template location
- `## Dates` — the cycle: deadlines, notification, camera-ready (absolute
  dates, never "next month")
- `## Standing` — submissions in flight and past outcomes, linked to their
  `manuscript-` pages
- `## Facts` — contacts, portal URLs, quirks of the submission system

## Ask the user for
- Which template/class file is current, portal credentials location (never
  values), the exact dates.

## Naming
- `venue-<name-slug>.md`, e.g. `venue-ieee-tmi.md`, `venue-orchard-press.md`.

## Typical relations
- Targeted by `manuscript-` pages; editors/reviewers as `entity-` pages.
