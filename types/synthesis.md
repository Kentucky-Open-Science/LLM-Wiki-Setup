# synthesis — an answer worth keeping

- **Tier**: core (always included)
- **Prefix**: `synthesis-`
- **Purpose**: a cross-cutting analysis, comparison, or connection — usually
  filed back from a good answer to a real question, so the reasoning is never
  redone. The page answers: the question it was written for.

## Signals
Core — no evidence needed. (Created by the query workflow, not seeded.)

## Required sections
- `## Question` — the query this answers, verbatim if possible
- `## Answer` — with inline citations (`[[page]]` links and provenance tags)
- `## Sources` — every page and external source drawn on

## Ask the user for
- Nothing beyond the original question — a synthesis cites existing verified
  material; it introduces no new unverified facts.

## Naming
- `synthesis-<question-slug>.md`,
  e.g. `synthesis-why-storms-spike-anomaly-flags.md`.

## Typical relations
- Cites broadly; superseded when underlying pages change — `audit` checks
  syntheses against their sources' `updated` dates.
